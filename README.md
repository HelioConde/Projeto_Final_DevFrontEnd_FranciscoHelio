# Projeto Final — Desenvolvimento Front-End

**Projeto final de formação em desenvolvimento front-end, com páginas estáticas e recursos visuais.**

## Tecnologias e arquivos

- `index.html` — página inicial.
- `css/` — estilos.
- `js/` — scripts de interface.
- `view/` — páginas complementares.
- `img/` e `icon/` — imagens e ícones.

## Executar

Sirva a pasta por HTTP, por exemplo:

```bash
python -m http.server 8000
```

Abra `http://localhost:8000`.

## Sobre este repositório

Este é um projeto histórico de estudo. Para avaliar as funcionalidades, explore as páginas e os arquivos presentes. Não há pipeline de testes ou build documentado nesta revisão.
